# 町CGI（TOWN ver.1.40）PHP 8.3 移植版 [PHPver.0.9]

brassiere 氏作「町CGI ver.1.40」（Perl / Shift_JIS）を PHP 8.3 / UTF-8 に移植したものです。
ゲームの内容・画面・データ形式は元のまま、保存方式の選択（テキストファイル / SQLite）とセキュリティ対策を追加しています。

- 原作: 町CGI Copyright (c) 2003-2004 brassiere（http://brassiere.jp/）
- 画面下部の作者表示、JavaScript 内の著作権表示は元のまま残しています。

---

## 動作環境

- PHP 8.3 以上
- 拡張モジュール: `mbstring`、`session`（SQLite 方式を使う場合は `pdo_sqlite` も）
- Apache（.htaccess 有効）または nginx 等

## 設置手順

1. フォルダ一式をサーバーにアップロードします。
2. `data/` フォルダに Web サーバーから書き込めるようにします（例: `chmod -R 770 data`、所有者を Web サーバーのユーザーに）。
3. **`town_ini.php` の `$admin_pass` を必ず変更**してください。
   初期値（`1234`）や空欄のままでは管理画面に入れません。
   平文のほか、`php -r "echo password_hash('新しいパスワード', PASSWORD_DEFAULT);"` で作ったハッシュ値も使えます。
4. ブラウザで `index.php`（または `town_maker.php`）を開きます。
5. トップ画面下の「管理者メニュー」から管理者パスワードでログインし、「街のレイアウト作成」で街を作ってください（元の CGI と同じ手順です）。

その他の設定項目（街の名前・地価・行動制限時間など）も `town_ini.php` にあり、元の `town_ini.cgi` と同じ名前・意味です。

### nginx の場合

`.htaccess` は効かないため、次のように `data/`・`lib/`・`tools/` へのアクセスを禁止してください。

```nginx
location ~ ^/(data|lib|tools)/ { deny all; }
location ~ \.(cgi|dat|sqlite)$ { deny all; }
location = /town_ini_local.php { deny all; }
```

`data/` は Web 公開フォルダの外に置くこともできます（`town_ini.php` の `$data_dir` で指定）。

## データの保存方式（テキストファイル / SQLite）

`town_ini.php` の `$storage_type` で切り替えます。

| 設定 | 保存先 |
|---|---|
| `'file'`（初期値） | `data/` 以下のテキストファイル（元の CGI と同じ形式・UTF-8） |
| `'sqlite'` | `$sqlite_file`（初期値 `data/town.sqlite`）の 1 ファイル |

- どちらの方式でも、1 回のアクセスを 1 つの排他処理として扱うため、元のロックディレクトリ方式より同時アクセス時のデータ破損が起きにくくなっています。
- SQLite 方式に切り替えて最初にアクセスしたとき、SQLite ファイルが空なら `data/` のテキストデータを自動で取り込みます。
- 手動で移行・バックアップする場合は `tools/migrate.php` を使います（コマンドラインで実行）。

```sh
php tools/migrate.php file-to-sqlite              # テキスト → SQLite
php tools/migrate.php sqlite-to-file ./backup     # SQLite → テキスト（バックアップにも）
```

## 旧 Perl 版からのデータ移行

```sh
php tools/migrate.php import-perl /path/to/旧townフォルダ
```

`log_dir`・`member`・`dat_dir`・`guestlog.cgi` を Shift_JIS → UTF-8 に変換して `data/` にコピーします。
旧データのパスワードは平文で保存されていますが、各ユーザーが次にログインしたときに自動でハッシュ化されます。

## セキュリティ強化の内容

| 対策 | 内容 |
|---|---|
| パスワードのハッシュ化 | `password_hash()` で保存。管理画面や登録完了画面にも表示しません |
| パスワードを画面・URL に出さない | 元はすべてのフォームにパスワードを埋め込んでいました。ログイン後はセッションに紐づくトークンに置き換えています |
| CSRF 対策 | 上記トークンはセッションと一致しないと無効。セッション Cookie は HttpOnly / SameSite=Lax |
| XSS 対策 | 入力値の `< > " '` を実体参照に変換。引用符なしの HTML 属性に値が入る箇所は自動で `"…"` で囲み、JavaScript 文字列に入る箇所は専用にエスケープ |
| URL 入力の検証 | キャラ画像・アイコン・独自 URL は `http://` / `https://` のみ受け付け（`javascript:` 等は破棄） |
| ファイルパスの検証 | ID・街番号などは数字のみ。保存層でも `..` 等のパスを拒否 |
| 数値入力の検証 | 金額・数量などは 0 以上の整数のみ（マイナス入金による増殖等を防止） |
| 改ざん対策 | 建築費・ローン融資額・デパート/個人店/卸問屋の購入価格を、ブラウザから送られた値ではなくサーバー側で再計算 |
| 内部コマンドの偽装防止 | 管理者用の `command=from_system`（振込の残高チェック省略）は管理者のみ有効 |
| 管理者認証 | 初期パスワードのままでは無効。ログイン失敗時は待ち時間を入れて総当たりを抑制 |
| Cookie | パスワードは保存しません（名前のみ） |
| HTTP ヘッダ | `X-Content-Type-Options`・`X-Frame-Options`・`Referrer-Policy` を送信 |
| データの保護 | `data/`・`lib/`・`tools/` への直接アクセスを .htaccess で禁止 |

## 元の CGI からの変更点（意図的なもの）

- 文字コードを UTF-8 に変更。元のソースの「表\示」問題による文字化けも解消しています。
- Flash（`happen.swf`）の再生と、外部バナー（macler.com）の表示を削除しました（どちらも現在は動作しません）。
- 登録完了画面・管理画面でパスワードを表示しなくなりました（管理画面では「変更する場合のみ入力」）。
- ホスト名の逆引きは初期設定でオフ（IP アドレスで多重登録判定）。`$host_lookup = '1'` で元の動作になります。
- 文字数制限は元と同じく Shift_JIS 換算のバイト数（全角 = 2）で判定します。

## 既知の制限

- 個人のお店の「販売価格は仕入れ価格の 3 倍まで」の判定は元と同じくブラウザから送られた仕入れ価格を使います（影響は自分のお店の価格設定のみ）。
- 元のゲームの仕様・バランスはそのままです。

## OGP（SNS で共有されたときの表示）

各ページにタイトル・説明文・画像の OGP / Twitter カード用タグを出力します。`town_ini.php` で設定できます。

- `$ogp_url` … サイトの URL（空欄ならアクセスされた URL から自動判定。リバースプロキシ配下などでずれる場合は指定してください）
- `$ogp_description` … 説明文
- `$ogp_image` … 画像（初期値は同梱の `img/ogp.png`。ゲーム内の GIF を並べて作った 1200×630 の画像です）

タイトルは `$title`（街の名前）が使われます。

Twitter（X）カードも `town_ini.php` で設定できます。

- `$twitter_card` … `'summary_large_image'`（大きい画像）／`'summary'`（小さい画像）／`''`（出力しない）
- `$twitter_site` / `$twitter_creator` … サイト・作成者のアカウント（例: `'@example'`。空欄なら出力しない。形式が正しくない場合も出力しません）
- `$twitter_image` … カード用の画像（空欄なら `$ogp_image` を使用）
- `$twitter_image_alt` … 画像の説明（代替テキスト）

## スマホ対応

画面はスマートフォンでも操作できるよう、HTML と CSS を書き直しています（画像は元の GIF をそのまま使用）。

- 共通のスタイルは `css/town.css` にまとめています。色や角丸などは先頭の変数（`--tw-accent` など）で変えられます。
- 街の画面・トップ画面・ステータス・コマンドボタン・メッセージ／エラー画面は、カード型のレイアウトに作り直しました。
  - 幅の広い画面では地図とステータスが左右に並び、スマホでは縦に並びます（トップ画面ではログイン欄が先）。
  - 地図は 32px の GIF のまま、横スクロールで表示します。
  - PC 幅（960px 以上）では、地図の列がスクロールに追従します（列が画面より高いときは列の中でスクロール）。
  - スマホではマウスを乗せたときの説明が出ないため、コマンドボタンには名前を表示しています。
  - 地図・あいさつ・街の情報・コマンド・ステータス・能力値・参加者の各枠は、見出しを押すと開閉できます（開閉状態はブラウザごとに記憶）。
- 元の「[前の画面に戻る]」（ブラウザの戻る＝`history.back()`）は廃止し、「戻る」ボタンに置き換えました。
  住民としてログイン中は街の画面、管理者は管理者メニュー、ログイン前はトップページに戻ります。
- その他の施設画面（銀行・デパート・学校など）は元の HTML のまま、CSS で次のように調整しています。
  - 固定幅の表は画面幅に合わせ、説明とタイトル画像の 2 段組は縦に積む
  - 列の多い表（商品一覧など）は横スクロール
  - 入力欄・ボタンを指で押しやすい大きさに
- 列の多い表の判定に CSS の `:has()` を使っているため、古いブラウザ（2023 年以前の Firefox など）では一部の表が横に広がったまま表示されます。

旧来のタグは置き換えています（`<font>` → `<span style=…>`、`<b>` → `<strong>`、`<center>` → `<div style=text-align:center>`）。
HTML の属性値はすべて引用符で囲んでいます（`method=POST` → `method="POST"` など）。
なお、旧版から移行したデータ（あいさつ・掲示板の過去ログなど）に保存済みの `<font>` 等はそのまま残りますが、表示は従来どおりです。

## ファイル構成

```
index.php            トップページ（town_maker.php を表示）
town_maker.php ほか  ゲーム本体（元の .cgi / .pl に対応）
town_ini.php         設定ファイル
town_ini_local.php   （任意）設定の上書き用。置くと town_ini.php の後に読み込まれます
lib/                 共通処理（保存層・Perl 互換関数・入力処理と認証）
tools/migrate.php    データ移行ツール
css/town.css         画面のスタイル（スマホ対応）
img/                 画像（元のまま）
data/                ゲームデータ（書き込み権限が必要）
```

ゲーム本体の PHP は元の Perl のサブルーチン・変数名・コメントをそのまま残しているので、元の CGI の改造情報を参考に手を入れられます。
`lib/runtime.php` には Perl と PHP の違い（空文字列の数値計算、`split` の挙動など）を吸収する関数が入っています。

## 動作確認について

移植時に、元の Perl 版と PHP 版を同じ条件（乱数・時刻を固定）で並べて動かし、新規登録・銀行・仕事・学校・ジム・食堂・デパート・建築・家の設定・掲示板・お店・メール・挨拶・競馬・カード・病院・温泉・プロフィール・恋人斡旋所・告白・キャラ作成・Cリーグ・街コンテスト・役場・管理者機能など 400 以上の操作について、画面出力と保存データが一致することを確認しています（テキストファイル方式・SQLite 方式の両方）。
差分は上記「意図的な変更点」によるものだけです。
